# Проект: Облачное веб-приложение «Список задач»

Этот проект представляет собой веб-приложение для управления личными задачами. Оно написано на чистом HTML, CSS и JavaScript без использования сторонних фреймворков. 

В качестве бэкенда (базы данных) используется облачная платформа Supabase. Приложение умеет регистрировать пользователей, входить в аккаунт и сохранять задачи в облако.

К концу курса в этом репозитории появится полноценный сервис с возможностью редактирования задач, а также мы улучшим дизайн приложения и добавим новые функции.
